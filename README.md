## 🏗️ What I Like Building

I'm particularly interested in backend systems where **architecture and reliability matter**.

Some areas I've worked on:

### Multi-Tenant Systems

Designing systems where tenants are isolated while sharing a common platform.

* Tenant-specific databases
* Tenant resolution and context propagation
* Automated tenant provisioning
* Database isolation
* Tenant-aware distributed communication

### Distributed Workflows

Building reliable asynchronous workflows using:

**RabbitMQ + MassTransit + Kubernetes + gRPC**

including retry mechanisms and failure recovery for partially completed operations.

### Performance Optimization

I enjoy finding bottlenecks and improving systems rather than simply adding infrastructure.

Examples include:

* SQL query and stored procedure optimization
* Reducing unnecessary database calls
* Improving API response times
* Caching frequently accessed data
* Optimizing report-generation workflows
